Kablo Bağlantısı

YF-S201 ile ESP32-WROOM-32U arasındaki 3 kablo bağlantısı:

YF-S201 Kablosu Renk ESP32 Pin Açıklama
Kırmızı Güç VIN (5V) Sensörü besler, 5V gerektirir
Siyah Toprak GND Ortak negatif hat
Sarı Sinyal GPIO 4 Darbe sinyali — her darbe = 2.25 mL
⚠
YF-S201 sinyal hattı 5V sürer. ESP32 GPIO pinleri 3.3V toleranslıdır. Aradaki 10kΩ pull-up direnç bu gerilim farkını dengeler. Direnç olmadan pin zamanla hasar görebilir.
✔
Breadboard üzerinde: kırmızı kablo VIN sütununa, siyah GND sütununa, sarı GPIO4 pinini 10k ohm direnç üzerinden 3.3V'a bağlayarak breadboard'a takabilirsiniz. Jumper kablolarla lehimsiz kurulum yaparsınız.

Arduino Kodu (ESP32)

Aşağıdaki kod interrupt tabanlı darbe sayımı yapar, L/dakika hesaplar ve her 2.5 saniyede bir JSON gönderir. WiFi SSID/şifresi ile sunucu IP'sini kendi ortamınıza göre değiştirin.

ℹ
Arduino IDE'de File → Preferences → Additional Board Manager URLs altina https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json ekleyin, ardından ESP32 by Espressif Systems paketini yükleyin.
C++ / Arduino susayar_esp32.ino 
// ================================================================
// Su Sayar — ESP32 Firmware
// Sensor : YF-S201 Akış Sensörü (GPIO 4)
// Cikis  : HTTP POST JSON → Node.js backend
// ================================================================

#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>  // Arduino IDE Library Manager'den yükleyin

// ---- KONFIGÜRASYON — burayı değiştirin ----
const char* WIFI_SSID     = "WiFi_Adiniz";
const char* WIFI_PASS     = "WiFi_Sifreniz";
const char* SERVER_URL    = "http://192.168.1.100:3000/api/sensor"; // sunucu IP:PORT
const char* DEVICE_ID     = "susayar-001";  // cihaz kimlik kodu
const int   SENSOR_PIN    = 4;              // YF-S201 sinyal pini
const int   SEND_INTERVAL = 2500;           // milisaniye (2.5 sn)
// -------------------------------------------

// YF-S201: 1 darbe = 2.25 mL (üretici kalibrasyon değeri)
// Frekans (Hz) = debi (L/dak) x 7.5 → debi = frekans / 7.5
const float PULSE_TO_ML = 2.25;

volatile unsigned long pulseCount  = 0;
unsigned long          lastSendMs  = 0;
unsigned long          lastCountMs = 0;
float                  totalLiters = 0.0;
unsigned long          sessionStart;

// Interrupt servis rutini — her sensör darbesi bu fonksiyonu çağırır
IRAM_ATTR void onPulse() {
  pulseCount++;
}

void setup() {
  Serial.begin(115200);
  pinMode(SENSOR_PIN, INPUT_PULLUP);
  // RISING kenarda interrupt başlat (her darbede pulseCount artar)
  attachInterrupt(digitalPinToInterrupt(SENSOR_PIN), onPulse, RISING);

  Serial.println("Su Sayar başlıyor...");
  connectWiFi();
  sessionStart = millis();
  lastSendMs   = millis();
  lastCountMs  = millis();
}

void loop() {
  unsigned long now = millis();

  if (now - lastSendMs >= SEND_INTERVAL) {
    // Interrupt'ı geçici olarak devre dışı bırak, sayacı oku ve sıfırla
    detachInterrupt(digitalPinToInterrupt(SENSOR_PIN));
    unsigned long count = pulseCount;
    pulseCount = 0;
    attachInterrupt(digitalPinToInterrupt(SENSOR_PIN), onPulse, RISING);

    // Geçen süre (saniye cinsinden)
    float elapsed = (now - lastCountMs) / 1000.0;
    lastCountMs = now;

    // Debi hesabi: darbe_frekansı / 7.5 = L/dak
    float freqHz  = count / elapsed;           // darbe/saniye
    float flowLpm = freqHz / 7.5;              // L/dakika
    float volumeMl = count * PULSE_TO_ML;       // bu aralikta gecen hacim (mL)
    totalLiters += volumeMl / 1000.0;          // kumulatif toplam (L)

    // WiFi bağlantisi kopmussa yeniden baglan
    if (WiFi.status() != WL_CONNECTED) connectWiFi();

    // HTTP POST ile sunucuya veri gönder
    sendData(flowLpm, totalLiters, count);

    lastSendMs = now;
  }
}

void sendData(float flowLpm, float totalL, unsigned long pulses) {
  HTTPClient http;
  http.begin(SERVER_URL);
  http.addHeader("Content-Type", "application/json");

  // JSON payload oluştur
  StaticJsonDocument<256> doc;
  doc["device_id"]   = DEVICE_ID;
  doc["flow_lpm"]    = round(flowLpm * 100) / 100.0;  // 2 ondalik
  doc["total_liters"] = round(totalL  * 10)  / 10.0;   // 1 ondalik
  doc["pulses"]      = pulses;
  doc["uptime_sec"]  = (millis() - sessionStart) / 1000;
  doc["rssi_dbm"]    = WiFi.RSSI();  // sinyal gücü — debug için

  String payload;
  serializeJson(doc, payload);

  int statusCode = http.POST(payload);

  if (statusCode == 200) {
    Serial.printf("[OK] %.2f L/dak | Toplam: %.1f L\n", flowLpm, totalL);
  } else {
    Serial.printf("[HATA] HTTP %d\n", statusCode);
  }

  http.end();
}

void connectWiFi() {
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  Serial.print("WiFi bağlanılıyor");
  int attempts = 0;
  while (WiFi.status() != WL_CONNECTED && attempts < 20) {
    delay(500);
    Serial.print(".");
    attempts++;
  }
  if (WiFi.status() == WL_CONNECTED) {
    Serial.printf("\nBağlandı! IP: %s\n", WiFi.localIP().toString().c_str());
  } else {
    Serial.println("\nWiFi bağlantısı başarısız — 30sn sonra tekrar deneniyor");
    delay(30000);
    ESP.restart();  // bağlanamassa yeniden başla
  }
}

Node.js Backend

ESP32'den gelen HTTP POST isteklerini karşılayan, veriyi bellekte tutan ve WebSocket üzerinden dashboard'a anlık ileten basit bir Express sunucusu.

  • Node.js 18+ yüklü olduğundan emin olun
  • Yeni klasör oluşturun: mkdir susayar-backend && cd susayar-backend
  • Bağımlılıkları yükleyin: npm init -y && npm install express ws cors
  • Aşağıdaki kodu server.js olarak kaydedin
  • Çalıştırın: node server.js
JavaScript server.js 
// ================================================================
// Su Sayar — Node.js Backend
// HTTP: ESP32'den JSON alır
// WebSocket: Dashboard'a canlı veri yayar
// Çalıştır: node server.js
// ================================================================

const express = require('express');
const { WebSocketServer } = require('ws');
const cors    = require('cors');
const http    = require('http');

const app    = express();
const PORT   = process.env.PORT || 3000;

app.use(cors());
app.use(express.json());
app.use(express.static('public'));  // dashboard HTML dosyaları buradan servislenir

// Son 500 okuma bellekte tutulur (geçmiş grafiği için)
const readings = [];
const MAX_HISTORY = 500;

// ── HTTP endpoint: ESP32 buraya POST atar ──────────────────────
app.post('/api/sensor', (req, res) => {
  const data = req.body;

  // Temel doğrulama
  if (typeof data.flow_lpm !== 'number' || typeof data.total_liters !== 'number') {
    return res.status(400).json({ error: 'Gecersiz payload' });
  }

  // Sunucu taraflı timestamp ekle
  const reading = { ...data, ts: new Date().toISOString() };

  // Geçmiş kayıt
  readings.push(reading);
  if (readings.length > MAX_HISTORY) readings.shift();

  // WebSocket üzerinden tüm bağlı dashboard istemcilerine yay
  broadcast({ type: 'sensor_update', payload: reading });

  console.log(`[${reading.ts}] debi: ${data.flow_lpm} L/dak | toplam: ${data.total_liters} L`);
  res.json({ ok: true, received: reading.ts });
});

// ── Son N okumayı getir (dashboard sayfa yenileme sonrası geçmiş) ──
app.get('/api/history', (req, res) => {
  const n = Math.min(parseInt(req.query.n) || 100, MAX_HISTORY);
  res.json(readings.slice(-n));
});

// ── En son okumayı getir ───────────────────────────────────────
app.get('/api/latest', (req, res) => {
  if (readings.length === 0) return res.json({ flow_lpm: 0, total_liters: 0 });
  res.json(readings[readings.length - 1]);
});

// ── WebSocket sunucusu ────────────────────────────────────────
const server = http.createServer(app);
const wss    = new WebSocketServer({ server });

wss.on('connection', ws => {
  console.log('Dashboard bağlandı. Aktif istemci:', wss.clients.size);

  // Yeni bağlanan istemciye son okumayı hemen gönder
  if (readings.length > 0) {
    ws.send(JSON.stringify({ type: 'sensor_update', payload: readings[readings.length - 1] }));
  }

  ws.on('close', () => console.log('Dashboard ayrıldı. Aktif:', wss.clients.size));
});

function broadcast(msg) {
  const str = JSON.stringify(msg);
  wss.clients.forEach(client => {
    if (client.readyState === 1) /* OPEN */ client.send(str);
  });
}

server.listen(PORT, '0.0.0.0', () => {
  console.log(`Su Sayar backend çalışıyor: http://localhost:${PORT}`);
  console.log(`ESP32 POST adresi: http://<SUNUCU_IP>:${PORT}/api/sensor`);
});

API endpoint özeti:

En son sensör okuması. Dashboard'un sayfa yenileme sonrası anlık veriyi çekmesi için kullanılır.

Python Backend (Alternatif)

Node.js yerine Python tercih ediyorsanız aşağıdaki FastAPI versiyonunu kullanabilirsiniz. Her iki backend de aynı API arayüzünü sunar.

  • Python 3.10+ yüklü olduğundan emin olun
  • Bağımlılıkları yükleyin: pip install fastapi uvicorn websockets
  • Aşağıdaki kodu server.py olarak kaydedin
  • Çalıştırın: uvicorn server:app --host 0.0.0.0 --port 3000 --reload
Python server.py 
# ================================================================
# Su Sayar — Python / FastAPI Backend
# Çalıştır: uvicorn server:app --host 0.0.0.0 --port 3000 --reload
# ================================================================

from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.middleware.cors import CORSMiddleware
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel
from datetime import datetime, timezone
from collections import deque
import asyncio, json
from typing import Optional

app = FastAPI(title="Su Sayar API")

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

# Son 500 okuma bellekte (deque otomatik eski kaydı siler)
readings: deque = deque(maxlen=500)
clients:  list  = []  # bağlı WebSocket istemcileri

class SensorReading(BaseModel):
    device_id:    str
    flow_lpm:     float
    total_liters: float
    pulses:       Optional[int] = 0
    uptime_sec:   Optional[int] = 0
    rssi_dbm:     Optional[int] = 0

# ── POST /api/sensor — ESP32'den veri al ──────────────────────
@app.post("/api/sensor")
async def receive_sensor(reading: SensorReading):
    data = reading.model_dump()
    data["ts"] = datetime.now(timezone.utc).isoformat()
    readings.append(data)

    # Tüm bağlı istemcilere yay
    msg = json.dumps({ "type": "sensor_update", "payload": data })
    dead = []
    for ws in clients:
        try:
            await ws.send_text(msg)
        except:
            dead.append(ws)
    for ws in dead:
        clients.remove(ws)

    print(f"[{data['ts']}] debi: {data['flow_lpm']} L/dak | toplam: {data['total_liters']} L")
    return { "ok": True, "received": data["ts"] }

# ── GET /api/latest ───────────────────────────────────────────
@app.get("/api/latest")
async def get_latest():
    if not readings:
        return { "flow_lpm": 0, "total_liters": 0 }
    return readings[-1]

# ── GET /api/history?n=100 ────────────────────────────────────
@app.get("/api/history")
async def get_history(n: int = 100):
    n = min(n, 500)
    return list(readings)[-n:]

# ── WebSocket /ws — dashboard bağlantısı ─────────────────────
@app.websocket("/ws")
async def websocket_endpoint(ws: WebSocket):
    await ws.accept()
    clients.append(ws)
    print(f"Dashboard bağlandı. Aktif: {len(clients)}")

    # Yeni istemciye son okumayı hemen gönder
    if readings:
        await ws.send_text(json.dumps({
            "type": "sensor_update", "payload": readings[-1]
        }))

    try:
        while True:
            await ws.receive_text()  # bağlantı sağlığını koru
    except WebSocketDisconnect:
        clients.remove(ws)
        print(f"Dashboard ayrıldı. Aktif: {len(clients)}")

Dashboard Entegrasyonu

Su Sayar dashboard'ını gerçek sensörden gelen veriye bağlamak için aşağıdaki JavaScript snippet'ini dashboard HTML dosyanızın <script> bloguna ekleyin.

ℹ
Demo modda dashboard kendi simüle ettiği veriyi kullanır. Gerçek mod için REAL_MODE = true yapıp WS_URL'i sunucu adresinizle güncelleyin.
JavaScript dashboard entegrasyon 
// ================================================================
// Su Sayar Dashboard — Gerçek Sensör Entegrasyonu
// Bu blogu mevcut dashboard'unuzun <script> etiketine ekleyin
// ================================================================

const REAL_MODE = false;  // true yapınca canlı veri aktif olur
const WS_URL    = 'ws://192.168.1.100:3000/ws';  // backend WebSocket adresi

let wsConnection = null;
let reconnectTimer = null;

function connectRealSensor() {
  if (!REAL_MODE) return;  // demo modda WebSocket açılmaz

  clearTimeout(reconnectTimer);
  wsConnection = new WebSocket(WS_URL);

  wsConnection.addEventListener('open', () => {
    console.log('[Su Sayar] Sensor baglandı');
    updateConnectionBadge(true);
  });

  wsConnection.addEventListener('message', (e) => {
    try {
      const msg = JSON.parse(e.data);
      if (msg.type === 'sensor_update') applyRealData(msg.payload);
    } catch (err) {
      console.warn('[Su Sayar] Parse hatası', err);
    }
  });

  wsConnection.addEventListener('close', () => {
    updateConnectionBadge(false);
    console.log('[Su Sayar] Bağlantı koptu, 5sn sonra tekrar denenecek...');
    reconnectTimer = setTimeout(connectRealSensor, 5000);
  });

  wsConnection.addEventListener('error', (err) => {
    console.error('[Su Sayar] WebSocket hata', err);
    wsConnection.close();
  });
}

function applyRealData(data) {
  // Dashboard DOM elementlerini gerçek veriyle güncelle
  const flowVal  = parseFloat(data.flow_lpm  || 0);
  const totalVal = parseFloat(data.total_liters || 0);

  // Anlık debi
  const flowEl = document.getElementById('flow-value');
  if (flowEl) flowEl.textContent = flowVal.toFixed(1);

  // Gün toplamı
  const todayEl = document.getElementById('today-val');
  if (todayEl) todayEl.textContent = Math.round(totalVal);

  // Akış ring animasyonu (KPI halka grafiği)
  const ring = document.getElementById('flow-ring');
  if (ring) {
    const pct = Math.min((flowVal / 15) * 100, 100);  // 15 L/dak = max kabul
    ring.style.background =
      `conic-gradient(var(--accent) ${pct}%, var(--surface2) ${pct}%)`;
  }

  // Durum metni
  const statusEl = document.getElementById('flow-status');
  if (statusEl) {
    if      (flowVal === 0)   statusEl.textContent = 'Akış yok';
    else if (flowVal <  0.5) statusEl.textContent = 'Düşük debi — damlatma?';
    else                      statusEl.textContent = 'Akış aktif';
  }
}

function updateConnectionBadge(connected) {
  const badge = document.getElementById('connection-badge');
  if (!badge) return;
  badge.textContent = connected ? 'Canlı' : 'Bağlantı yok';
  badge.style.background = connected ? 'rgba(46,160,67,.2)' : 'rgba(231,111,81,.2)';
  badge.style.color       = connected ? '#7ee787' : '#ff7b72';
}

// Sayfa yüklendiğinde başlat
document.addEventListener('DOMContentLoaded', connectRealSensor);

Yaygın sorunlar

WiFi bağlanamıyor

SSID/şifre doğru mu? 2.4 GHz ağda mı? (ESP32 5 GHz desteklemez)

HTTP 0 ya da -1

SERVER_URL'deki IP doğru mu? Bilgisayar ve ESP32 aynı ağda mı?

Debi hep 0

GPIO 4 pinine sarı kablo bağlı mı? 10kΩ pull-up direnç var mı?

Kalibrasyon notu: YF-S201'in kalibrasyon katsayısı kablo uzunluğuna ve basınç farklılıklarına göre değişebilir. Gerçek ölçüm ile karşılaştırarak PULSE_TO_ML değerini (varsayılan 2.25 mL) ayarlayın. Örnek test: 1 litre su geçişindeki darbe sayısını sayıp 1000 / darbe_sayisi mL değerini hesaplayın.
